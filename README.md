# 🚀 Apex Planet Internship - Task 2

## 📌 Project Title
Responsive Login & Registration UI with Validation and AJAX Basics

---

## 📖 About the Project
This project is developed as part of the **Apex Planet Internship (Task 2)**.  
It focuses on building a modern, responsive, and user-friendly authentication UI using frontend technologies.

The system includes Login and Registration pages with form validation, password handling features, and basic AJAX functionality to simulate username/email checking without page reload.

---

## ✨ Features

### 🔐 Login Page
- Email & Password input fields
- Show/Hide password toggle
- Form validation
- Responsive design

### 📝 Registration Page
- Username, Email, Password, Confirm Password fields
- Password match validation
- Show/Hide password feature
- Required field validation

### ⚡ AJAX Feature (Basic)
- Checks username/email availability (dummy PHP logic)
- No page reload required
- Use XAMPP server:
Place project inside htdocs
Start Apache
Run in browser:
http://localhost/project-folder/

### 📱 UI/UX
- Mobile-first responsive design
- Bootstrap 5 grid system
- Clean and modern interface
- Hover effects and smooth transitions
- Google Fonts and Bootstrap Icons integration
